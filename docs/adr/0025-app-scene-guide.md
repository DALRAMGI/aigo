# 0025. 현장 모드를 상황별 단계 안내로 바꾸고, 앞선 앱 디자인 변경을 기록한다

- 상태: 제안
- 날짜: 2026-11-10
- 변경 작업자: 최재혁 (DALRAMGI), Claude(AI) 사용
- 관련 PR: 미정

## 작업 내용
### 이번 변경: 사고 현장 모드 상황별 안내 (`apps/app`)
- 고정 체크리스트 6줄(`SceneBody.tsx`의 `CHECKLIST`)을 없애고 `SceneGuide`로 바꿨다.
- 첫 질문 "다친 사람이 있나요?"(네, 있어요 / 아니요, 차만 / 모르겠어요)와 "고속도로·자동차전용도로예요" 스위치로 단계를 고른다.
  - 다친 사람 있음(모르겠어요 포함): 119 → 2차 사고 막기 → 다친 사람 곁에 있기 → 112 → 현장 기록 → 상대 정보 → 보험사·가족
  - 차만 부딪힘: 비상등 → 차 옮기기 전 사진 → 차 옮기기 → 상대 정보(책임 인정 말 하지 않기) → 보험사 → 112가 필요한 경우
  - 고속도로: 비상등·트렁크 → 가드레일 밖 대피 → 안전삼각대(할 수 있을 때만) → 112 → 도로공사 무료 견인(1588-2504)을 맨 앞에 붙이고, 겹치는 비상등 단계는 뺀다.
- 단계마다 표지판처럼 읽히는 아이콘 타일을 둔다. 급한 단계는 빨간 타일, 아이콘을 누르면 완료(파란 체크), 제목을 누르면 자세한 방법과 바로가기 버튼(112, 119, 무료 견인, 보험사, 현장 사진)이 열린다.
- 파일: `src/lib/scene-guide.ts`(안내 데이터), `src/components/SceneGuide.tsx`(화면), `src/components/SceneBody.tsx`, `src/components/ui/Icon.tsx`(아이콘 10개 추가), 테스트 `src/lib/scene-guide.test.ts`, `src/components/scene.test.tsx`

### 앞선 변경(PR #53으로 이미 dev에 머지됨): ADR 규칙 도입 전이라 여기 함께 기록한다. ADR 0018의 색(Supabase)과 홈 배치 일부를 대체한다
- 앱 색을 채도를 낮춘 파랑(#3A64C4)·남색(#1A2B4C)으로 시험 적용, `onBrand` 토큰 추가
- 홈 A안: DashPi 기기 카드(준비 중, 연결 점), 사고 났어요 / 분석 결과 두 갈래, "사고 영상, 바로 분석해요" 메인 카드, 오른쪽 위 알림 버튼
- 알림 화면(`/notifications`): 완료·실패한 분석을 알림으로 표시, 읽음은 폰에만 저장
- 현장 모드 '알릴 사람' 카드: 가족·지인 연락처 최대 5명, 전화·문자, 폰에만 저장

## 변경 사유
- 앱 디자인 담당(최재혁)이 디자인 결과를 최종 개발자(조준형)에게 전달하기 위한 변경이다.
- 기존 체크리스트는 모든 사고에 같은 6줄을 보여 줘서, 크게 다치지 않은 접촉사고에도 119 신고를 안내하는 등 허술해 보였다(최재혁 발견). 국내 사고의 다수는 경미한 접촉사고이고, 상황(부상 여부, 고속도로)에 따라 해야 할 일과 순서가 다르다.
- 글이 많아지면 한눈에 읽히지 않아, 도로 표지판처럼 아이콘으로 단계를 알아보게 했다.
- 안내 근거: 한국도로공사 2차 사고 예방 행동요령(비트밖스), 도로교통법 제54조(사고 후 조치), 도로공사 긴급견인(1588-2504). 안전삼각대는 현재 정해진 거리 기준이 없어 "뒤차가 충분히 볼 수 있는 곳, 도로 위를 무리하게 걷지 않기"로 안내한다.

## 영향
- 현장 모드는 여전히 로그인·인터넷 없이 동작한다. 112·119 버튼은 화면 맨 위에 그대로 있다.
- 답을 고르기 전에는 단계가 보이지 않는다. 질문 카드가 첫 화면에 있어 한 번 누르면 된다.
- 완료 체크는 화면을 벗어나면 초기화된다(저장하지 않음).
- 확인: `pnpm exec tsc --noEmit`, `pnpm test` 95개 통과(새 테스트 6개). 웹 미리보기로 화면 확인. Android 실기기·개발 빌드 확인은 하지 못했다.
- 남은 일: 안내 문구는 법률·의료 자문을 받지 않은 일반 안내다. 필요하면 전문가 검토를 받는다.
