# 0026. 앱 화면 바탕을 살짝 어둡게 하고, 영상 분석하기 첫 카드를 파랑으로 바꾼다

- 상태: 제안
- 날짜: 2026-11-10
- 변경 작업자: 최재혁 (DALRAMGI), Claude(AI) 사용
- 관련 PR: 미정

## 작업 내용
- 화면 바탕색 토큰 `bg`(#EBEBEB)를 추가하고 `Screen`의 바탕을 `gray3`(#F0F0F0)에서 `bg`로 바꿨다. 모든 화면의 바탕이 아주 살짝 어두워진다. 카드(흰색 #FFFFFF)는 그대로다.
- 영상 분석하기 화면(`src/app/(tabs)/upload.tsx`)에서 영상을 고르기 전에 보이는 "어떤 영상을 분석할까요?" 카드를 흰색에서 앱 파랑(`brand`)으로 바꿨다. 아이콘 원은 반투명 흰색, 글자는 흰색, "갤러리에서 영상 고르기"는 흰 버튼(secondary)이다.
- `EmptyState`에 파란 바탕 위에서 쓰는 `tone="brand"`를 추가했다. 다른 화면의 `EmptyState`는 바뀌지 않는다.

## 변경 사유
- 앱 디자인 담당(최재혁)이 디자인 결과를 최종 개발자(조준형)에게 전달하기 위한 변경이다.
- 바탕과 흰 카드의 차이가 작아 카드가 또렷하게 보이지 않았다. 바탕을 아주 조금 어둡게 해서 흰 부분이 더 하얗게 보이게 했다.
- 영상 분석하기 첫 카드를 홈의 "사고 영상, 바로 분석해요" 카드, 하단 메뉴의 영상 버튼과 같은 파랑으로 맞춰 같은 기능임을 한눈에 알게 했다.

## 영향
- 바탕색만 바뀌므로 화면 배치와 동작은 같다.
- 확인: `pnpm exec tsc --noEmit` 통과, `pnpm test` 통과. 웹 미리보기로 화면을 확인했다. Android 실기기 확인은 하지 못했다.
- ADR 0025(사고 현장 모드) PR과 `docs/adr/README.md` 목록 줄이 겹친다. 0025가 먼저 머지되면 이 브랜치를 dev에 맞춰 다시 올린다.
